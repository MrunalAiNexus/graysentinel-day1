GraySentinel Day 1 is a two-project cybersecurity portfolio demonstrating an end-to-end security assessment workflow. Project 1 performs authorized web reconnaissance and enumeration, collecting structured technical information and evidence from controlled targets. Project 2 builds on this reconnaissance data by validating, prioritizing, documenting, and reporting security findings with risk analysis and remediation guidance. Together, the projects demonstrate practical skills in cybersecurity, ethical hacking, Python automation, security assessment, evidence-based analysis, and professional security reporting.
